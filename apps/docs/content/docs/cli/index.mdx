<Callout type="info" title="Coming soon">
  The `pushstack` CLI (also installed as `pst`) is not released yet.
</Callout>

It will be a `gh`-compatible command line over the [REST API](/docs/api): sign in with a personal
access token, then list, view and create repositories, issues and pull requests. Progress is
tracked in [issue #45](https://github.com/nandan-varma/pushstack/issues/45).
