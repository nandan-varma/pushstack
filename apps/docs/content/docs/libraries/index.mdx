title: Libraries
description: git-fs-s3 and git-edge, the two packages PushStack's git layer is built from.
---

PushStack's git layer is extracted into two published npm packages, developed in this repository
under `packages/`.

<Cards>
  <Card title="git-fs-s3" href="/docs/libraries/git-fs-s3">
    An isomorphic-git filesystem backend for S3-compatible object storage, plus a smart-HTTP
    handler and a git-hosting operations layer.
  </Card>
  <Card title="git-edge" href="/docs/libraries/git-edge">
    Object-level three-way merge and parsed-object caches for isomorphic-git, with no worktree and
    no `node:*` imports.
  </Card>
</Cards>
